Part 2 — Public /browse vs Explore tab (anonymous)

11. Anonymous landing — Find Help Nearby hero, "Your area" chip, Speak, Browse by category, Live Now zones, Featured providers.
12. Header search icon → public /browse?browse=0 ✅ — "Search nearby" page, category chips, Featured/Online/Rating, Suggestions. Anonymous-safe, no sign-in redirect.
