# User Journeys (Consumer/Seeker)

## Journey 1: First-Time User → First Booking

1. **Landing** → Sees ServiQ landing page (locality-specific)
2. **Intent Selection** → "Who are you?" card: Find Help / Earn Nearby / Set Up Business
3. **Sign Up** → Email, phone OTP, Google, or Apple auth
4. **Onboarding** → Select locality, basic profile setup
5. **Need Post** → "I need an electrician" → AI parses intent → category, urgency, budget
6. **Provider Matching** → AI matches top providers by proximity, trust, availability
7. **Compare** → See matched providers with trust scores, reviews, quotes
8. **Connect** → Send connection request or start chat
9. **Quote** → Receive and compare quotes
10. **Book** → Accept quote → Create order → Pay via Razorpay
11. **Track** → Real-time status updates (accepted → in_progress → completed)
12. **Review** → Rate and review the provider

## Journey 2: Returning User → Quick Need

1. **Open App** → Personalized feed based on locality
2. **Post Need** → Quick need creation (AI pre-fills from history)
3. **Match** → Instant provider matches
4. **Book** → One-tap booking with saved payment

## Journey 3: Browse & Discover

1. **Explore Tab** → See nearby providers, categories, zones
2. **Search** → AI-powered natural language search
3. **Provider Profile** → View trust score, reviews, portfolio
4. **Direct Chat** → Message provider directly
5. **Book** → Create order from provider profile
