# Provider Journeys

## Journey 1: New Provider → First Completed Job

1. **Sign Up** → Choose "Earn Nearby" or "Set Up Business"
2. **Launchpad** → Step-by-step business profile creation
   - Business name, type, category
   - Location, contact info
   - Description, services offered
3. **Profile Setup** → Complete profile (target: 70%+ completion)
   - Add services with pricing
   - Add portfolio items
   - Set availability schedule
   - Upload verification documents
4. **Verification** → Email → Phone → Identity → Business
5. **First Lead** → Help request match notification
6. **Quote** → Create and send quote with line items
7. **Negotiate** → Quote room chat with consumer
8. **Accept** → Consumer accepts quote → Order created
9. **Complete** → Mark order as completed
10. **Get Paid** → Payment processed, payout eligible
11. **Get Review** → Consumer leaves review → Trust score updates

## Journey 2: Established Provider → Growth

1. **Dashboard** → View orders, earnings, reviews
2. **Subscription** → Upgrade to Essential/Premium
3. **Featured** → Purchase featured placement
4. **Workspace** → Create team, add members
5. **Branches** → Add multiple service locations
6. **Analytics** → View performance metrics
7. **Referrals** → Earn by referring other providers
