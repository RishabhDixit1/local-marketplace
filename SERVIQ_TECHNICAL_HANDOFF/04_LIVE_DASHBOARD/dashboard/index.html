Category Demand
Category Requests Providers Conversion Rate
[QUERY REQUIRED] Run the category demand query below and populate this table
SELECT sc.name, count(DISTINCT o.id) AS requests, count(DISTINCT s.profile_id) AS providers,
round(count(DISTINCT o.id)::numeric / nullif(count(DISTINCT s.profile_id), 0), 2) AS conversion
FROM service_categories sc
LEFT JOIN services s ON s.category_id = sc.id AND s.is_active
LEFT JOIN orders o ON o.category_id = sc.id
GROUP BY sc.name ORDER BY requests DESC
